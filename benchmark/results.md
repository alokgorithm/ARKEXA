# Benchmark results

**Not run yet.** The corpus has not been collected, so there are no numbers on
this page and none will be invented to fill it.

When it is run, this file will be regenerated by `python benchmark/run.py
--write` and will carry:

- the corpus size and its split between vulnerable and clean
- precision, recall, true positives, false positives and false negatives for
  ARKEXA, zizmor and poutine
- the total number of findings each tool emitted, next to its precision
- the pinned version of every tool, and the date

A precision claim from three releases ago is not a precision claim, so this
page is regenerated whenever a rule changes.

See [METHODOLOGY.md](../METHODOLOGY.md) for how the corpus is built and
labelled, and [README.md](README.md) for the mechanics.
