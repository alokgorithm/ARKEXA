# ARK005 `agent-writes-default-branch`

|  |  |
|---|---|
| Severity | high |
| OWASP Agentic Top 10 (2026) | ASI06 Insufficient Human Oversight |
| Introduced in | v0.1 |

An agent job pushes to the default branch or merges with --admin.

A job that runs an agent also pushes straight to the default branch, or merges
a pull request with `--admin`, which skips required reviews. That removes the
last checkpoint: whatever the agent produced is on main without anyone reading
it, and on main it runs in every subsequent workflow.

The safe shape is for the agent to open a pull request. A pull request is the
review gate, and it costs nothing to keep.

Fix: push to a branch and open a pull request, drop `--admin`, and let a human
or a required check merge.

## Reported

```yaml
# ARK005: agent output reaches the default branch with no review.
name: Docs bot
on:
  issue_comment:
    types: [created]

jobs:
  docs:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - name: Rewrite the docs
        run: claude -p "Update the changelog"
      - name: Ship it
        run: |
          git commit -am "docs: update"
          git push origin main
```

## Not reported

```yaml
# Safe: the agent's work goes through a pull request, which is the review gate.
name: Docs bot
on:
  issue_comment:
    types: [created]

jobs:
  docs:
    runs-on: ubuntu-latest
    permissions:
      contents: write
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
      - name: Rewrite the docs
        run: claude -p "Update the changelog"
      - name: Open a pull request
        uses: peter-evans/create-pull-request@v6
        with:
          branch: docs-bot/changelog
          title: Update the changelog
```

Both files live in [`tests/fixtures`](../../tests/fixtures) and are checked on
every run, so the safe one is a promise, not a claim.

## Reachability

This rule, like every other, is reported only when the job it lives in can be
triggered by the level you asked for. By default that means `external`: any
GitHub account. Add `--reachability all` to see findings that need write
access to reach.

## Suppressing it

```yaml
# .arkexa.yml
ignore:
  - rule: ARK005
    path: .github/workflows/example.yml
    reason: why this one is acceptable
```

A `reason` is required. An ignore without one is reported and not applied.
